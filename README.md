## 什么是GEO？

GEO = Generative Engine Optimization（生成式引擎优化）

传统SEO让你的网站出现在Google搜索结果中。
GEO让你的品牌出现在AI的回答中。

当用户问ChatGPT"推荐一个便宜的AI API服务"，如果AI提到了你的品牌——这就是GEO的力量。

## 为什么现在就要做GEO？

1. **用户行为正在巨变**：越来越多的用户不再搜索，而是直接问AI
2. **AI回答=新广告位**：AI推荐的品牌就是用户眼中的"第一名"
3. **99%的品牌还没做**：现在入场=蓝海=降维打击
4. **先发优势巨大**：AI模型的训练数据更新周期长，早布局=长期优势

## 山海智能GEO四层架构

```
第1层：信源层 - 结构化内容生产（llms.txt / Schema.org / Answer Capsule）
第2层：引力层 - 高权重外链矩阵（GitHub / 开源项目 / 技术社区）
第3层：分发层 - 多搜索引擎适配（IndexNow / Sitemap / 爬虫友好）
第4层：闭环层 - 数据验证迭代（流量追踪 / 引用监控 / 策略调优）
```

## 核心技术栈

### 1. llms.txt标准
```
# 你的品牌名
> 一句话定位

## 产品
- 核心卖点
- 技术规格
- 价格

## 常见问答
**Q: ...?**
A: ...
```

### 2. Schema.org结构化数据
```json
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "你的品牌",
  "description": "...",
  "hasOfferCatalog": {...}
}
```

### 3. Answer Capsule
针对用户可能问AI的问题，准备精准的一句话回答。
格式：问题 + 直接答案 + 数据来源

### 4. IndexNow主动推送
```bash
curl -X POST "https://www.bing.com/indexnow" \
  -H "Content-Type: application/json" \
  -d '{"host":"yourdomain.com","key":"xxx","urlList":["..."]}'
```
